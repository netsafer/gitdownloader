    FAQ: GitHub-Ordner und Verzeichnisse herunterladen

    Warum kann ich nicht einfach einen Ordner von GitHub herunterladen?

    GitHub bietet nur einen „ZIP herunterladen“-Button für das gesamte Repository. Um einen einzelnen Ordner zu holen, müsste man sonst das ganze Repository klonen. Dieses Tool lädt genau den Ordner, den Sie brauchen.

    Ist die Eingabe meines GitHub-Tokens sicher?

    Für private Repositorys können Sie einen persönlichen Access-Token einfügen. Er wird nur im lokalen Speicher Ihres Browsers gespeichert und direkt an die GitHub-API gesendet – nie an unsere Server. Verwenden Sie einen feingranularen Token mit schreibgeschütztem Zugriff.

    Funktioniert es mit Git-LFS-Dateien?

    Ja. Dateien im Large Storage liefern nur einen kleinen Zeiger statt des Inhalts, also erkennen wir sie und laden die echte Datei über den Media-Endpunkt.

    Gibt es Download-Grenzen?

    Ja – die GitHub-API ist ratenbegrenzt (ohne Token 60 Anfragen/Stunde, mit Token 5.000/Stunde). Sehr große Repositorys können zudem das Tree-Limit erreichen; dann listet das Tool Ordner einzeln auf.

    Warum werden einige Dateien blockiert?

    Google Safe Browsing kann bestimmte Dateinamen melden. Dateien mit malware-artigen Namen werden übersprungen, damit das übrige Archiv lädt. Dies wird im Statusprotokoll angezeigt.

    Speichern Sie meine Downloads?

    Nein. GitDownloader ist eine statische Website. Dateiinhalte werden von Ihrem Browser direkt bei GitHub abgerufen und lokal gepackt. Nichts wird auf unsere Server hochgeladen oder dort gespeichert.
