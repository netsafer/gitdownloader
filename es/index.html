    FAQ: descargar carpetas y directorios de GitHub

    ¿Por qué no puedo descargar simplemente una carpeta de GitHub?

    GitHub solo ofrece un botón «Descargar ZIP» para todo el repositorio. Para una sola carpeta tendrías que clonar todo el repositorio. Esta herramienta descarga solo la carpeta que necesitas.

    ¿Es seguro introducir mi token de GitHub?

    Para repositorios privados puedes pegar un token de acceso personal. Se guarda únicamente en el almacenamiento local de tu navegador y se envía directamente a la API de GitHub — nunca a nuestros servidores. Usa un token de solo lectura y alcance preciso.

    ¿Funciona con archivos Git LFS?

    Sí. Los archivos de Large Storage devuelven un pequeño puntero en lugar del contenido real, así los detectamos y descargamos el archivo desde el endpoint de medios.

    ¿Hay límites de descarga?

    Sí — la API de GitHub tiene límites de peticiones (60/hora sin token, 5.000/hora con uno). Los repositorios muy grandes también pueden alcanzar el límite de truncado del endpoint tree, y entonces la herramienta lista las carpetas una a una.

    ¿Por qué se bloquean algunos archivos?

    Google Safe Browsing puede marcar ciertos nombres de archivo. Se omite cualquier archivo cuyo nombre parezca malware para que el resto del archivo ZIP se descargue igualmente. Se muestra en el registro de estado.

    ¿Almacenáis mis descargas?

    No. GitDownloader es un sitio estático. El contenido de los archivos lo obtiene tu navegador directamente de GitHub y se empaqueta localmente. Nada se sube ni se guarda en nuestros servidores.
