Términos

Última actualización: 2026-01-01

Al acceder a GitDownloader aceptas estos términos. La herramienta se ofrece «tal cual» para descargar contenido público o autorizado de GitHub.

Uso aceptable

Usa la herramienta solo para descargar contenido al que tienes permiso para acceder. Respeta la licencia de cada repositorio; descargar no otorga derechos adicionales sobre los archivos.

Sin garantía

El servicio se proporciona sin garantías de ningún tipo. No garantizamos la disponibilidad, la exactitud ni que una descarga tenga éxito, ya que depende de la API de GitHub y sus límites.

Limitación de responsabilidad

En la máxima medida permitida por la ley, no nos hacemos responsables de daños derivados del uso de la herramienta o del contenido que descargues.

Servicios de terceros

GitDownloader se basa en la API de GitHub. Tu uso de GitHub está sujeto a los propios términos y políticas de GitHub.

Cambios

Podemos actualizar estos términos de vez en cuando. El uso continuado de la herramienta tras los cambios constituye la aceptación de los términos revisados.
