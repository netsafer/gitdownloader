    FAQ : télécharger des dossiers et répertoires GitHub

    Pourquoi ne puis-je pas simplement télécharger un dossier depuis GitHub ?

    GitHub ne propose un bouton « Télécharger le ZIP » que pour le dépôt entier. Pour un seul dossier, il faudrait cloner tout le dépôt. Cet outil ne télécharge que le dossier dont vous avez besoin.

    Est-il sûr de saisir mon jeton GitHub ?

    Pour les dépôts privés, vous pouvez coller un jeton d’accès personnel. Il n’est stocké que dans le stockage local de votre navigateur et envoyé directement à l’API GitHub — jamais à nos serveurs. Utilisez un jeton granulaire en lecture seule.

    Est-ce compatible avec les fichiers Git LFS ?

    Oui. Les fichiers du grand stockage renvoient un petit pointeur au lieu du contenu, nous les détectons et téléchargeons le vrai fichier via le point de terminaison média.

    Y a-t-il des limites de téléchargement ?

    Oui — l’API GitHub est limitée (60 requêtes/heure sans jeton, 5 000/heure avec). Les très grands dépôts peuvent aussi atteindre la limite de troncature de l’API tree ; l’outil liste alors les dossiers un par un.

    Pourquoi certains fichiers sont-ils bloqués ?

    Google Safe Browsing peut signaler certains noms de fichiers. Les fichiers dont le nom évoque un logiciel malveillant sont ignorés afin que le reste de l’archive se télécharge quand même. C’est indiqué dans le journal d’état.

    Stockez-vous mes téléchargements ?

    Non. GitDownloader est un site statique. Le contenu des fichiers est récupéré par votre navigateur directement depuis GitHub et compressé localement. Rien n’est envoyé ni conservé sur nos serveurs.
