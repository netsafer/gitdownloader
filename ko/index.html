깃허브 폴더 다운로드: 필요한 디렉터리만 ZIP으로

GitHub는 저장소 전체 ZIP만 제공하므로 깃허브 디렉터리 다운로드는 보통 전체를 클론하는 일이 됩니다. 위에 URL을 붙여넣으면 필요한 폴더, 하위 폴더 또는 파일만 받아 ZIP으로 묶어 줍니다. 비공개 저장소와 Git LFS도 지원하며 모든 처리는 브라우저에서 실행됩니다.

    실패한 다운로드를 재시도하고 거대하거나 잘린 디렉터리도 안정적으로 처리합니다.

    깃허브 폴더·디렉터리 다운로드 FAQ

    GitHub에서 폴더만 바로 다운로드할 수 없는 이유는 무엇입니까?

    GitHub는 저장소 전체에 대해서만 “Download ZIP” 버튼을 제공합니다. 폴더 하나만 가져오려면 보통 저장소 전체를 클론해야 합니다. 이 도구를 사용하면 필요한 디렉터리만 다운로드할 수 있습니다.

    GitHub 토큰을 입력해도 안전합니까?

    비공개 저장소의 경우 개인 액세스 토큰을 붙여넣을 수 있습니다. 토큰은 사용자의 브라우저 로컬 스토리지에만 저장되고 GitHub API로 직접 전송되며 저희 서버로는 전송되지 않습니다. 필요한 특정 저장소에 대한 읽기 전용 권한만 가진 세분화된 토큰을 사용하세요.

    Git LFS 파일도 지원합니까?

    지원합니다. 대용량 저장소 파일은 실제 내용 대신 작은 포인터를 반환하므로, 이를 감지해 GitHub 미디어 엔드포인트에서 실제 파일을 다운로드합니다.

    다운로드 제한이 있습니까?

    있습니다. GitHub API에는 요청 한도가 있습니다(토큰 없이 시간당 60회, 토큰 사용 시 시간당 5,000회). 저장소가 매우 크면 tree API의 잘림 한도에 도달할 수 있으며, 이 경우 도구가 폴더를 하나씩 나열하는 방식으로 대체합니다.

    일부 파일이 차단되는 이유는 무엇입니까?

    Google 세이프 브라우징이 특정 파일 이름을 위험 요소로 표시할 수 있습니다. 악성코드로 보이는 이름의 파일은 건너뛰어 나머지 압축 파일은 정상적으로 다운로드되도록 합니다. 이 내용은 상태 로그에 표시됩니다.

    제 다운로드를 저장합니까?

    아니요. GitDownloader는 정적 웹사이트입니다. 파일 내용은 브라우저가 GitHub에서 직접 가져와 로컬에서 압축합니다. 저희 서버로 업로드되거나 보관되는 것은 없습니다.
