    FAQ: baixar pastas e diretórios do GitHub

    Por que não consigo simplesmente baixar uma pasta do GitHub?

    O GitHub só oferece o botão “Download ZIP” para o repositório inteiro. Para pegar uma única pasta, você normalmente teria que clonar o repositório todo. Esta ferramenta permite baixar apenas a pasta que você precisa.

    É seguro informar meu token do GitHub?

    Para repositórios privados, você pode colar um token de acesso pessoal. Ele fica salvo apenas no armazenamento local do seu próprio navegador e é enviado direto para a API do GitHub — nunca para os nossos servidores. Use um token de granularidade fina com acesso somente leitura aos repositórios que você precisa.

    Funciona com arquivos do Git LFS?

    Sim. Os arquivos de armazenamento grande retornam um pequeno ponteiro em vez do conteúdo real, então nós os detectamos e baixamos o arquivo de verdade pelo endpoint de mídia do GitHub.

    Existem limites de download?

    Sim — a API do GitHub tem limite de requisições (60 por hora sem token, 5.000 por hora com token). Repositórios muito grandes também podem atingir o limite de truncamento da API de árvore; nesse caso, a ferramenta passa a listar as pastas uma a uma.

    Por que alguns arquivos são bloqueados?

    O Google Safe Browsing pode sinalizar certos nomes de arquivo. Todo arquivo com nome parecido com malware é ignorado para que o restante do pacote ainda seja baixado. Isso aparece no registro de status.

    Vocês armazenam meus downloads?

    Não. O GitDownloader é um site estático. O conteúdo dos arquivos é buscado pelo seu navegador direto do GitHub e compactado localmente. Nada é enviado aos nossos servidores nem guardado neles.
